AIインターフェース（window.octa）

ブラウザのコンソールや Playwright から、プログラムやLLMでこのゲームを操作できます。AIモードでは時間は step() を呼んだ分だけ進みます（ターン制のように扱える）。

octa.rules()                      // ルールと仕様の説明（LLMに渡す用）
// Node なら src/core を直接使える（tools/agent-headless.ts）
octa.start({mission:'m1', difficulty:'easy', seed:1,
  loadout:[{slot:1,chassis:'heavy',weapon:'rifle',equip:'plate'}, ...]})
octa.observe()                    // 見えている情報だけのJSON
octa.text()                       // ASCIIマップ付きの文章版（LLM向け）
octa.act([{cmd:'move',units:[1,2],x:12,y:9},
          {cmd:'attack',units:[3],target:'e17'},
          {cmd:'stance',units:[6],stance:'nofire'}])
octa.step(1.0)                    // 1秒進めて observe() を返す
octa.replay()                     // 直前の戦闘のリプレイJSON
octa.playReplay(json,{speed:4})   // リプレイを画面で再生

別ページに埋め込んだ場合は postMessage({octa:1,id,method:'act',args:[...]}) でも呼べます（返信は同じ id で届く）。

操作方法
  • 左クリック/タップで味方を選択。左ドラッグで範囲選択、Shift+クリックで追加選択。1〜8で機体選択、E（またはCtrl+A）で全機。
  • 命令は右クリック：選択中に地面を右クリックで移動、敵を右クリックで攻撃目標指定（タッチ操作ではタップ）。左クリックは選択だけで、機体は動かない。
  • WASD・矢印キー、右/中ドラッグ、タッチのドラッグで画面スクロール。マップ上にカーソルを置くと右上に地形・機体の情報が出る。ミニマップのクリックで移動、マウスホイールでズーム。
  • Tツール使用（選択機のツール。もう一度押すと種類を切替、Escで取消）　Space一時停止　F倍速　X停止　Q交戦姿勢の切替（待機射撃→自由交戦→射撃禁止）　C選択機へカメラ移動
  • 森林は移動が遅いが、中にいる機体は見つかりにくく被弾が減る。丘陵の上では索敵と射程が+1。
  • 狙撃砲は索敵範囲より射程が長い。軽量機やレーダー装備機で敵を捉えてから撃つ。
